# 🤖 My Personal AI Assistant Chatbot

An AI-powered personal assistant chatbot designed to help students with coding, learning, problem-solving, and everyday questions through an interactive chat interface.

## 📌 About the Project

**My Personal AI Assistant Chatbot** is a web-based application built to provide an interactive and student-friendly AI experience. It helps users understand programming concepts, get coding assistance, and explore topics through natural-language conversations.

The project combines a modern frontend with a Node.js backend to provide a foundation for an intelligent personal assistant.

## ✨ Features

- 💬 **AI Chat Interface** — Interact with the assistant through a chat interface.
- 💻 **Coding Assistance** — Get help understanding code and programming concepts.
- 📚 **Student Support** — Useful for learning, studying, and problem-solving.
- 🌐 **Hindi Language Support** — Designed to support Hindi-based interactions.
- 🗂️ **Chat History** — Sidebar for recent conversations and navigation.
- 🎨 **Interactive UI** — Modern interface with a student-friendly design.
- ⚙️ **Backend Integration** — Node.js and Express backend for handling chat requests.

## 🚀 Getting Started

### Prerequisites

Install the following tools before running the project:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### 1. Clone the Repository

```bash
git clone https://github.com/manishjadhav9529/My-Personal-AI-Assistant-Chatbot.git
```

### 2. Open the Project Folder

```bash
cd My-Personal-AI-Assistant-Chatbot
```

### 3. Install Dependencies

Run `npm install` in the backend directory and, if the frontend has its own `package.json`, run it there too.

```bash
npm install
```

### 4. Configure Environment Variables

Create a local `.env` file if your application requires API keys or other configuration.

Example:

```env
PORT=5000
# Add your required AI API key using the variable name expected by your code
```

**Security:** Never commit API keys, passwords, or `.env` files to GitHub.

### 5. Run the Application

Start the backend using the start command defined in your `package.json`, for example:

```bash
node server.js
```

Start the React frontend separately using its configured development script, if applicable:

```bash
npm start
```

Check your project's `package.json` files for the exact commands and required configuration.
