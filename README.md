# 🤖 My Personal AI Assistant Chatbot

An AI-powered personal assistant chatbot designed to help students with learning, coding, problem-solving, and everyday questions through a simple and interactive web interface.

## 📌 About the Project

**My Personal AI Assistant Chatbot** is a web-based application developed to provide users with an interactive assistant for educational support and everyday queries.

The project includes a chatbot interface, user login and signup pages, an admin interface, and a Python backend. It aims to make learning easier by providing a convenient platform where students can ask questions and explore programming concepts.

## ✨ Features

- 💬 **Interactive Chatbot:** Communicate with the AI assistant through a user-friendly interface.
- 💻 **Coding Assistance:** Get support with programming concepts and technical questions.
- 📚 **Student Support:** Designed to assist with learning, studying, and problem-solving.
- 🔐 **Login System:** Provides a dedicated login page.
- 📝 **Signup Page:** Includes a page for user registration.
- 🛠️ **Admin Interface:** Provides an admin page for administrative functionality.
- 🎨 **User-Friendly Design:** HTML, CSS, and JavaScript create the web interface.
- ⚙️ **Python Backend:** Uses Python for server-side functionality.

## 🚀 Getting Started

Follow these steps to download and run the project locally.

### Prerequisites

Install the following software:

- Python 3
- Git
- A modern web browser
- A code editor such as Visual Studio Code

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/manishjadhav9529/My-Personal-AI-Assistant-Chatbot.git
```

### 2. Open the Project Folder

```bash
cd My-Personal-AI-Assistant-Chatbot
```

### 3. Start the Python Backend

Run the following command:

```bash
python server.py
```

If your system uses the Python launcher command, try:

```bash
py server.py
```

Follow the terminal output for the server address and port. If the application requires additional Python packages or API credentials, configure them according to the backend code.

### 4. Open the Web Application

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

If the chatbot communicates with the Python backend, keep the backend running and make sure the API endpoint configured in `Script.js` matches the server address.

**Note:** The exact startup procedure may depend on how `server.py` and the frontend are configured.
